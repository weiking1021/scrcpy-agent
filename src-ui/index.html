    While a device is usable, its battery, storage and the rest are read again. 0 turns this off.

    Screen and input

    With a physical keyboard you type with the computer's keys and the device's input method turns them into text, so Chinese can be typed. Set the keyboard layout once in the device's own settings (its physical keyboard page). It applies to screens opened afterwards.

    0 leaves it to scrcpy (8). A higher number gives a sharper picture and uses more of the connection; try 16 to 24 over Wi-Fi if text looks soft. It applies to screens opened afterwards.

    Show a toolbar with the screen window

    On Windows the toolbar sticks to the screen window and follows it. On other systems it is a separate window that you drag by its grip.
